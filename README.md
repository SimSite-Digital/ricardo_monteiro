# Ricardo Monteiro Advogados Associados

Pré-visualização do novo site do escritório Ricardo Monteiro
Advogados Associados, advocacia criminal em Cuiabá, Mato Grosso.

## Aviso

Esta é uma versão de demonstração, para aprovação do conteúdo e do
layout. Não é o site em produção.

- O formulário de contato não envia mensagem nesta versão.
- Algumas imagens são provisórias e serão substituídas.
- Informações marcadas entre colchetes aguardam confirmação do
  escritório.
- O site definitivo será publicado em ricardomonteiro.adv.br.

## Stack

Site estático em HTML, CSS e JavaScript puros, sem framework.
Build em Node sem dependências.

```bash
node build.mjs     # gera dist/
npx serve dist     # pré-visualiza
```
